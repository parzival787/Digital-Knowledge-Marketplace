# research_results

Retained synthetic simulator outputs and model artifact. These document a specific small benchmark, not quantum advantage or production retrieval accuracy. QAOA and VQC currently underperform their principal classical comparators.

### [QAOA_PRICING_REPORT.md](QAOA_PRICING_REPORT.md)

Project documentation for QAOA PRICING REPORT. Treat dated plans and old status notes as historical unless confirmed by current code/deployment.

### [VQC_EMBEDDINGS_REPORT.md](VQC_EMBEDDINGS_REPORT.md)

Project documentation for VQC EMBEDDINGS REPORT. Treat dated plans and old status notes as historical unless confirmed by current code/deployment.

### [qaoa_pricing.json](qaoa_pricing.json)

### [vqc_embeddings.json](vqc_embeddings.json)

### [vqc_model.npz](vqc_model.npz)

Fitted VQC/PCA/decoder arrays; binary experiment artifact, not a production search model.
